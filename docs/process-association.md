# 应用运行状态与进程关联

面板读取 Windows 实际运行进程，应用从桌面、开机自启或游戏平台打开都可参与检测。自动识别使用快捷方式目标、受约束的启动器交接信息和 Steam 安装目录。

如果某个应用状态仍不正确：

1. 在运行面板服务的电脑上保持该应用运行。
2. 在面板启动页点击该应用的「关联进程」图标。
3. 搜索实际进程名称，核对显示的路径，选择后保存。
4. 保存后自动刷新运行状态。关联只需操作一次；更改安装位置后可以重新关联，也可以解除关联。

进程列表来自面板服务所在电脑，需要填写有效访问令牌。不能读取路径的进程会标注；这类关联使用准确进程名辅助判断。不同程序可能使用同名进程，选择时应核对任务管理器中的实际进程。

关联记录仅用于状态识别，不单独授权停止应用。只有原有自动识别具备足够身份信息时，停止按钮才可用。

桌面发行版将关联保存在 `%LOCALAPPDATA%\NERV_Panel\process-associations.json`，跟随用户数据保留。源码版保存在项目根目录；设置 `NERV_PANEL_ROOT` 时保存在指定的数据目录。关联配置损坏或不可读时显示异常，不会自动覆盖。

Steam 安装状态按已安装标志位判断，兼容同时带有更新标记的游戏。
